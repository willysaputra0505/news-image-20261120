A program that sums up Friday 20 November 2026 world news in one image: the Shenzhen summit's peace declaration, Anthropic soaring 17% as markets slide, Kyiv hit by ballistic missiles, a tanker burning after a mine strike near Hormuz, the Senate's Iran war-powers vote, and mystery drones halting Genoa airport — plus four more stories below.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies the pre-rendered 1024x1024 poster (`entry.png`, 106,010 bytes) to the output directory, so both runs write identical bytes.
